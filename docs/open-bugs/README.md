## Run an issue

```sh
dotnet restore LiteDB.sln
dotnet build LiteDB.sln -c Release -p:TestingEnabled=true
dotnet test LiteDB.Tests/LiteDB.Tests.csproj -c Release -f net8.0 \
  -p:TestingEnabled=true --no-build --settings tests.runsettings \
  --filter FullyQualifiedName~Issue2803_
dotnet run --project LiteDB.ReproRunner/LiteDB.ReproRunner.Cli -c Release -- \
  run Issue_2803_CheckpointError --report /tmp/issue2803.json --report-format json
```

Use the linked runner/script notes for historical commits, repetitions, external
documentation, and actual Android/Windows commands. Run performance comparisons
without competing benchmarks. An all-pass intermittent run is evidence, not a
proof of a fix.
