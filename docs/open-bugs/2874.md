# Issue 2874: `ObjectId(byte[], int)` does not validate the input window

Source: https://github.com/litedb-org/LiteDB/issues/2874 (open on 2026-09-13).

## Contract and independent checks

Invalid caller-supplied byte windows must be rejected as argument errors rather than leaking an implementation-level `IndexOutOfRangeException`. The complementary control exercises several valid offsets, compares all 12 output bytes with an independently sliced source array, and also round-trips through the string constructor. This prevents a guard that rejects every non-zero offset from satisfying the negative test.
