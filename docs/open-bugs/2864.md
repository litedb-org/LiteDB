# Issue 2864: page-type ENSURE failures omit the type that was found

Source: https://github.com/litedb-org/LiteDB/issues/2864 (open on 2026-09-13; no comments).

## Contract and independent checks

`CollectionPage` and `IndexPage` must reject a mismatched on-disk page type with
error code `INVALID_DATAFILE_STATE`, and the exact diagnostic must identify both
the expected kind and the kind actually read from the page header.

The fixture writes the raw type byte directly at `BasePage.P_PAGE_TYPE` and
checks that byte before invoking either specialized reader. Expected names are
literal test data rather than values produced by LiteDB. Every defined
nonmatching page type is covered, as is unknown raw value `127`, so a hard-coded
suffix cannot satisfy the test. Two matching-type controls must construct
successfully and preserve the same raw header, preventing an always-throw fix.

The general variadic `ENSURE` formatter was already repaired by #2844. These
tests exercise the two still-unfixed page-reader call sites through that
formatter, including argument substitution.

## Observed on dev

Base: `89820a3b0a8575e6d126d0b7ff6a9b920dc2078b`; Release, Linux.
The test file was applied uncommitted on top of that exact SHA in an isolated
checkout.

```sh
dotnet test LiteDB.Tests/LiteDB.Tests.csproj -c Release -f net8.0 \
  -p:TestingEnabled=true --settings tests.runsettings \
  --filter FullyQualifiedName~Issue2864_ --logger 'console;verbosity=minimal'
```

Result: **12 failed, 2 passed, 0 skipped**. Every mismatch case received only
`page type must be collection page` or `page type must be index page`; all
twelve expected diagnostics additionally required `, but it is <actual-type>`.
Both matching-type controls passed. Assertions describe corrected behavior and
are neither skipped nor inverted.

As a satisfiability check, changing only the two calls in the disposable
checkout to pass `this.PageType` to the already-working formatted `ENSURE`
overload made the same command pass all 14 cases. Those source edits are not
part of this regression-test change.
