# Issue 2774: LiteDB.Shell ignores absolute Unix paths (arguments starting with / are parsed as options)

Source: https://github.com/litedb-org/LiteDB/issues/2774 (open in the initial inventory).

Reproduced on dev `90788bace880f477c9fb52ff7c0da98c9700bdfe`, Linux / .NET 8.
The test starts the actual shell, seeds a unique payload, and verifies the persisted
payload through a separate invocation. A timeout, missing payload, unexpected
file or changed original bytes fails the test. Exit code alone is insufficient.

Run after building the solution in Release with `-p:TestingEnabled=true`:

```sh
python3 scripts/regressions/issue_2774.py
```

Observed failure:

```text
absolute argument did not open the seeded database:
Welcome to LiteDB Shell

Getting started with `help`

> Database not connected
>
```
