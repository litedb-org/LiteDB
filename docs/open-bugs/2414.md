# Issue 2414: timezone-dependent test fixture

Source: https://github.com/litedb-org/LiteDB/issues/2414

The unchanged `Expressions_Scalar_Methods` test failed under `TZ=Asia/Tokyo`
on dev `90788bace880f477c9fb52ff7c0da98c9700bdfe`: expected day 1, actual 2.
The runtime correctly converts Extended JSON dates to local time. The fixture
assumed UTC calendar components and mixed local and UTC dates in DATEDIFF.

Corrected only the fixture. Added independent CLR calendar and UTC instant
oracles, including month/year boundaries. A production change that forces all
JSON dates to UTC will fail these checks in Tokyo or New York.

After a Release build with TestingEnabled=true, run:

```sh
python3 scripts/regressions/issue_2414.py
```

Executed successfully: 4 tests in each of UTC, Tokyo, and New York, 12 passed.
This fixes the reported test bug; no production implementation changed.
