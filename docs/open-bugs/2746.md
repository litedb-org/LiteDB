# Issue 2746: collection-name diagnostic omits the leading-digit rule

The reporter explicitly asks for an error explaining that collection names cannot
start with a number. Checking only `INVALID_COLLECTION_NAME` did not cover that
complaint. The new regression asserts the diagnostic's meaning, accepting either
an explicit leading-digit prohibition or a required initial letter, and requires
the rejected collection's actual name in the message.

The independent controls accept digits later in names, reject the reported name,
keep rejected writes out of the database, allow another write after failure, and
verify both committed rows after checkpoint and reopen. These checks precede the
diagnostic assertion. The test fails on **5.0.21 and dev `a50661a9`**, three of
three attempts each on 2026-09-15, because `Use only [a-Z$_]` omits the position rule.
